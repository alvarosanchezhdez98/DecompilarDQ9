European version

Overview Modules Source files In assembly

A function counts as decompiled when it's in a source file marked complete in its module's delinks.txt, since ninja min checks that those files build to the same bytes as the original. Functions whose C doesn't match yet are in assembly (NONMATCHING) and count as remaining.

The data in docs/status/data is generated from config/eur by python tools/progress.py --record, and CI checks that it's up to date. See progress.md, module-map.md and Decompiling.md.
